# Portrait frames

These nine images depict a fictional, generated person and are provided as replaceable demo assets.

For the smoothest cursor-following effect, replacement frames should:

- use identical canvas dimensions and lighting;
- keep the eyes, nose, and shoulders aligned;
- change only the head and eye direction;
- use the existing filenames exactly; and
- be compressed for the web before publishing.

The application preloads all frames and changes direction only after the cursor crosses a stable angular threshold.
