# Contributing

Thanks for helping improve Cursor & Covers.

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm run dev`.
3. Keep demo content fictional and do not commit personal data or third-party book artwork without permission.
4. Verify changes with `npm run build`.
5. Open a pull request describing the behavior and any accessibility or performance impact.

Bug reports and small, focused pull requests are welcome.
