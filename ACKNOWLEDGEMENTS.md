# Acknowledgements

Cursor & Covers builds on ideas shared by the open-source creative-coding community.

- [Face Looker](https://github.com/kylan02/face_looker) by kylan02 inspired the directional, cursor-following portrait workflow.
- [Complete Shelf](https://github.com/mintdotgg/mint-playground/tree/main/experiences/complete-shelf) from Mint Playground inspired the interactive 3D bookshelf and book-inspection experience.

This repository contains its own React and Three.js implementation, fictional demo content, procedurally rendered book designs, and a generated placeholder portrait. Consult each referenced project's repository for its current license and attribution requirements before copying code directly from it.
